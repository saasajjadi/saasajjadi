## Featured Project

### Profile Coverage Analysis

An ArcGIS Pro Python toolbox for estimating field observation coverage
along geological and mining exploration profiles.

The toolbox helps users:

- Assign observation points to profiles by name or nearest line
- Estimate covered and uncovered profile lengths and percentages
- Review point assignments and per-profile statistics
- Export GIS outputs and an Excel summary

**Important:** Covered length is estimated as the span between the
first and last matched observations. Gaps between observations are
included, so the result does not prove continuous traversal.

The current release is a **beta version**. Feedback and testing from
GIS, geology, and mining professionals are welcome.
